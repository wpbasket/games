# ttcLudo

A local-only Ludo board game built with pure Flutter.

## Features

- **Flexible Modes**: 2, 3, or 4 players in any Human, Bot, or Spectator setup.
- **Fair Dice**: Pure cryptographic randomness (`Random.secure()`).
- **Dynamic Rotation**: Auto-rotates the board to orient the human player at the bottom-left in single-player matches.
- **Native Flutter**: Zero third-party game frameworks. Custom board painter, 3D animated dice, and animated pawn physics.

## Getting Started

```bash
flutter run
```
